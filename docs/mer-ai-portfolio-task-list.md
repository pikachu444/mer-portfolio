## 운영 원칙

- 메르 직접 언급, 메르 산업 논지 기반 AI 추론, 단순 언급을 구분한다.
- 단순 언급은 관심종목으로만 남기며 포트폴리오에 편입하지 않는다.
- KOSPI200과 S&P500은 성과 비교용 벤치마크 데이터다. 모델 보유 자산으로 자동 편입하지 않는다.

글 수집·Gemini 분석·Telegram 전송을 수행하는 것이다. 구독 로그인 최초 연결을 운영

사용 권한·비용과 무인 실행을 별도 확인해야 하며 아직 구현하지 않았다.

실계정 미인증 상태는 [검증 기록](validation/chatgpt-provider-20261006.md)에 구분해 남긴다.
