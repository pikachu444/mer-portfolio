# 메르AI 포트폴리오 작업 목록

## 현재 작업

- [x] 광범위 지수 ETF 자동 편입과 20/40/20/20 고정 배분 제거
- [x] 개별주 10%, 섹터·산업 ETF 30% 목표비중 상한 적용
- [x] 잔여 비중을 현금으로 표시
- [x] Telegram과 HTML을 메르 글·투자 인사이트·근거 중심으로 정리

## 운영 원칙

- 메르 직접 언급, 메르 산업 논지 기반 AI 추론, 단순 언급을 구분한다.
- 단순 언급은 관심종목으로만 남기며 포트폴리오에 편입하지 않는다.
- KOSPI200과 S&P500은 성과 비교용 벤치마크 데이터다. 모델 보유 자산으로 자동 편입하지 않는다.
