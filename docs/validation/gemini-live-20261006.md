# Gemini 실제 호출 검증: 2026-10-06

기존 Gemini 요약·판단·운영 워크플로는 보존했다. 비교는 저장된 메르 글 12편과 동일한
현재 상태로 수행했고 Telegram 전송이나 운영 파일·성과 원장 갱신은 하지 않았다.
모의 응답 검사와 실제 모델 검사를 구분한다.

## 실제 비교에서 확인한 사실

[v1 양쪽 경로 실행](https://github.com/pikachu444/mer-portfolio/actions/runs/37399617077)은
생성 요청 4회와 정상 응답 4회를 기록했다. 일일 한도·rate limit 오류는 관찰되지 않았다.
남은 무료 quota를 조회한 결과는 아니다. 두 경로 모두 1회 교정 후에도 근거 검증에 실패했다.

| 경로 | 생성 요청 | 첫 응답 입력 토큰 | 정상 응답 | 최종 판단 검증 |
|---|---:|---:|---:|---|
| 기존 Gemini 입력 | 2 | 63,321 | 2 | 보유·증액 근거 연결 실패 |
| 개선 입력 v1 | 2 | 63,813 | 2 | 보유·증액 근거 연결 실패 |
| 개선 입력 v2 | 2 | 63,921 | 2 | 미검증 신규 국채 편입 실패 |
| 개선 입력 v3 | 2 | 64,004 | 2 | 1회 교정 후 공통 검사 통과 |

v1은 사용자 메시지 문자 수가 줄었지만 실제 첫 요청의 입력 토큰은 약 0.78% 늘었다.
따라서 입력 토큰 감소, 판단 품질 또는 수익률 개선을 입증하지 못했다. 정상 JSON·API
응답도 원문에 맞는 투자 판단을 보장하지 않는다.

v2·v3은 같은 입력 해시로 개선 경로만 각각 최대 2회 호출했다.
[v2 실행](https://github.com/pikachu444/mer-portfolio/actions/runs/37400614052)은 보류됐고
[v3 실행](https://github.com/pikachu444/mer-portfolio/actions/runs/37401152945)은 통과했다.
전체 생성 요청과 정상 응답은 각각 8회다. 한도 오류는 없었지만 남은 일일 한도는
조회하지 않았다. 각 버전·변형은 단일 입력의 한 번 실행이므로 통과율 향상을 입증하지 않는다.

처음에는 과거 인사이트 ID를 현재 응답에 없는 ID로 연결하는 오류도 발견했다. 교정 후
서로 다른 보유 판단의 새 신호 연결에서 다시 실패했다. 기존 오류 메시지는 인덱스만
알리고 종목·신호·방향·대상·원문 URL을 알려주지 않아 모델 교정에 부족했다.

## 실제 실행에서 고친 코드

- 비교 래퍼가 SDK 소유 객체를 유지하지 않아 연결이 닫히는 문제를 수정했다. 실제 SDK 객체가 수거되며 전송을 닫는 과정을 재현하는 회귀 테스트를 추가했다.
- `focused-source-v2`에서 기존 1회 교정에 종목·신호·방향·원문 대상·URL 진단을 추가했다. v3은 앞의 보유 오류로 최종 검사에서 아직 드러나지 않은 모든 신규 편입의 미검증 근거도 같은 교정에 포함한다. 출처를 바꾸거나 검증을 완화하지 않는다.
- 반대 근거는 위험·무효화 검토에서 설명하고 보유·매수의 지지 연결에 섞지 않도록 안내했다. 기존 연결은 실제로 논지가 유효할 때 유지하고 필요한 축소·매도를 피하도록 강요하지 않는다.
- 이번 응답에 작성한 인사이트만 연결하도록 안내했다. 과거 인사이트를 복사해 현재 응답에 없는 ID로 연결하지 않는다.

v2가 시도한 IEF 편입의 원문 신호 대상은 일반적인 `미국 국채`였고 특정 ETF 코드는
없었다. [2026-09-30 원문](https://blog.naver.com/ranto28/224426600100?fromRss=true&trackingCode=rss)의
“개인적으로 미국 국채는 일부 매수에 들어갔다.”는 캐시에서 대조해 일치한 인용이다.
메르의 국채 매수 발언과 AI가 IEF·만기를 고르는 판단을 구분해야 하는 사례다.
메르가 국채를 산 적이 없어서 차단한 것이 아니다.

## 최종 v3 포트폴리오와 한계

첫 응답은 보유 판단의 방향 연결 오류로 교정됐고 두 번째 응답이 기존 검사를 통과했다.
기존 6종목의 목표비중은 모두 유지됐다. 신규 국채 ETF 편입은 하지 않았고 IEF는
관심종목에 남았다. 계산된 자산 비중은 23%, 현금은 77%이며 기존 정책의 결과다.
새 현금 비율을 제안하거나 적용한 실험이 아니다.

| 종목 | 목표비중 | 판단 | 근거 상태 |
|---|---:|---|---|
| 한화오션 | 1.5% | 보유 유지 | 기존 미검증 근거 유지 |
| 삼성전자 | 1.5% | 보유 유지 | 기존 미검증 근거 유지 |
| SK하이닉스 | 5% | 보유 유지 | 기존 미검증 근거 유지 |
| KODEX 2차전지산업 | 5% | 보유 유지 | 기존 미검증 근거 유지 |
| KODEX 은행 | 7% | 보유 유지 | 기존 미검증 근거 유지 |
| KODEX 은선물(H) | 3% | 보유 유지 | 기존 미검증 근거 유지 |

모두 `legacy_unvalidated`였고 새로 검증된 근거가 생긴 결과가 아니다. 기존 관심종목의
IEF도 이 상태이며 메르 직접 판단이라는 레거시 표기와 구체적 상품 선택 사이의 문제는
남아 있다. 이 실행의 `valid`는 기존 정책에서 허용된 보유 유지와 신규 편입 차단을
통과했다는 뜻이다. 포트폴리오 전체의 경제적 타당성이나 원문 대상의 완전한 검증을
의미하지 않는다. 기존 종목의 무효화 검토가 충분한지도 추가 평가 대상이다.

최종 두 응답 입력 토큰은 64,004·64,595개, 생성 지연은 72.566·64.399초였다.
원문 인용 21개는 모두 캐시에서 일치했고 전후 운영 파일 해시는 같았다. Telegram
전송·운영 포트폴리오 반영·성과 원장 갱신은 없다. 검증 과정에서 글 요약을 다시
생성하지 않았으며 토큰 계산 요청은 위 생성 요청 상한과 별도다.

우선 개선한 것은 잘못 연결된 근거와 미검증 편입을 교정하는 과정이다. 다음 성과 평가에는
기존 미검증 종목의 원문 대상 재검토, 날짜별 당시 가용 입력 스냅샷, 가격·환율·매매비용과
고정 매매 규칙이 필요하다. 전체 근거 검증이나 수익률 개선을 완료로 표시하지 않는다.

## ChatGPT 직접 연결 시도

OpenAI OIDC 설정 조회와 새 PKCE 요청·콜백 리스너 준비에는 성공했다. 현재 클라우드
브라우저의 `127.0.0.1:1455` 접속이 `net::ERR_BLOCKED_BY_CLIENT`로 차단됐다. 계정 로그인·
승인과 토큰 발급은 진행하지 않았다. 임시 요청은 취소했고 저장된 계정은 없다.
브라우저와 코드가 콜백을 주고받을 수 있는 PC 또는 고정 자체 실행 호스트에서 연결해야 한다.

사용자가 GitHub 키를 복사하거나 터미널에서 비교 명령을 실행할 필요 없이 Gemini 실제
검증은 GitHub에서 실행했다. ChatGPT는 이 채팅의 로그인 세션을 코드에 넘겨 연결하는
방식이 아니며 해당 코드용 계정 승인과 실행 호스트가 필요하다.

전체 회귀 검사는 291개가 통과했고 [GitHub CI](https://github.com/pikachu444/mer-portfolio/actions/runs/37401157443)도
같은 291개와 API 없는 캐시 비교를 통과했다. 수익률 평가는 당시 가용 입력·가격·비용·매매 규칙을
고정한 별도 검증 대상이며 이번 API 연결과 근거 검증에 포함하지 않는다.
상세 측정은 [기계 판독 기록](gemini-live-20261006.json)에 남긴다.
