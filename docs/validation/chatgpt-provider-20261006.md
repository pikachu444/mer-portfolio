# 선택적 ChatGPT 판단과 메르 근거 개선 검증

Gemini 기본 자동화·글 요약·기존 문맥은 보존했다. 공식 ChatGPT 구독 로그인 제공자,
선택적 근거·문맥 개선, 운영을 바꾸지 않는 세 경로 비교 도구를 추가했다.
기준 입력은 커밋 `52a3f9d8f36bde8bc889a20a2f4b5f7e065bf6ad`의 저장된 메르 글과
포트폴리오다. 실제 투자 성과와 실계정 연결은 이 검증의 완료 범위에 포함하지 않는다.

## 구현과 독립 검토

세 독립 에이전트가 인증, 문맥 개선, 동일 입력 비교를 각각 구현하고 서로의 결과를 검토했다.

- 인증: 공식 PKCE·OIDC 서명/발급자/대상/nonce/주체 검증, 계정 분리, 회전 토큰의 잠금·원자적 저장, 완료된 스트림만 수용. 코드 교환 만료 시 같은 등록으로 한 번 새 인증을 시작하도록 보완했다.
- 문맥: 활성 보유·관심종목 필드와 원문 부모 연결을 보존하고 최신 반대 근거·검토 대기 위험을 남겼다. 현재 입력에 없던 부모 신호 3개를 복원하고 반복 이력을 줄였다.
- 비교: 동일 입력 복사본·공통 검증·실제 요청 직전 상한·실패 사용량 기록·입력 및 운영 파일 불변을 확인했다. 요청 예산 소진을 Gemini 서버 quota로 오인하는 재시도를 제거했다.

상호 검토에서는 혼합된 긍정·부정 표현을 무조건 반대 방향으로 바꾸거나 기존 보유를
강제 매도하지 않기로 했다. 새 편입·비중 증가가 그 근거에만 의존할 때 교정을 요청하고,
별도의 검증된 적합 근거가 있으면 기존 검증을 따른다. 단일 부정문 전체 의미를 해결한
것으로 해석하지 않는다. 외부 스냅샷 비교에서도 실제 운영 디렉터리 변경을 감지하도록 보완했다.

## 실제 캐시 입력 검사: 모델 호출 없음

| 범위 | 관련 글 | 인용 일치 | 기존 사용자 메시지 | 개선 사용자 메시지 | 문자 감소 | 생성 요청 |
|---|---:|---:|---:|---:|---:|---:|
| 일별 미분석 글 | 10 | 17/17 | 133,915자 | 126,101자 | 5.835% | 0 |
| 재조정: 2026-09-27 이후 | 12 | 21/21 | 137,187자 | 133,161자 | 2.935% | 0 |

두 실행 모두 운영 파일의 해시가 실행 전후 같았다. 숫자는 시스템 프롬프트·제공자별
스키마 지시·입력 크기 조정 전 사용자 메시지의 문자 수다. 모델 토큰·비용·수익률
감소 또는 증가를 의미하지 않는다. 최종 결과 요약과 입력·코드 해시는
[기계 판독 기록](chatgpt-provider-20261006.json)에 남겼다.

```bash
python compare_decisions.py --dry-run --run-type regular
python compare_decisions.py --dry-run --run-type rebalance
```

## 회귀 및 교정 흐름 검사: 전송은 모의 객체

`python -m unittest discover -s tests -v`: **288개 통과**. 기존 Gemini·출처·비중·출력
회귀 검사와 새 OAuth·스트림·제공자·문맥·비교 검사가 포함된다. 두 새 워크플로의 YAML
문법, Python 컴파일, `git diff --check`도 확인했다.

실제 `analyze.py` 실행 흐름에서 채권 가격에 부정적인 원문을 근거로 IEF 신규 편입을
제안하는 모의 응답이 교정 단계로 넘어가는 것을 확인했다. 공통 예산 1회에서는 두 번째
생성 요청이 차단되고, 2회에서는 수정 응답을 검증했다. 이는 실제 모델이 더 좋은
투자 판단을 했다는 결과가 아니다.

## 실계정 상태와 다음 비교

현재 실행 환경의 `chatgpt_auth.py status`에는 등록 계정이 없다. `--live`로 ChatGPT
경로의 사전 검사를 실행했지만 계정 미선택으로 생성 요청 전에 보류됐다. 요청 0회,
운영 상태 변경 없음, 종료 코드 1이다. 실모델 비교를 완료했다고 표시하지 않는다.

사용자가 브라우저가 있는 실행 호스트에서 `python chatgpt_auth.py login`을 한 번 승인하고
모델 목록을 확인하면 다음 명령으로 비교한다. GitHub에서 실행하려면
[고정 자체 실행 서버 설정](../chatgpt-login.md#github에서-비교-실행)이 추가로 필요하다.

```bash
python compare_decisions.py --live --run-type rebalance --max-requests 3
```

생성 요청 상한 3회는 세 경로가 각 한 번 성공할 때의 최소값이다. 앞선 경로의 교정이나
재시도가 예산을 쓰면 다음 경로가 생략된다. 비교 결과에서 통과율·교정 수·모델 사용량·
지연·편입과 비중 차이를 먼저 확인한다. 수익률 효과는 당시 가용 입력, 가격, 비용과
매매 규칙을 고정한 별도 시점별 검증으로 평가해야 한다. 이번 변경에서 ETF 교체나
새 비중 정책을 수익률 개선으로 간주하지 않았다.
