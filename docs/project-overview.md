# 메르AI 포트폴리오

메르 블로그 글을 수집해 LLM으로 요약하고, 글의 투자 논지와 참고 종목을 Telegram과 HTML 대시보드로 제공하는 프로젝트다. 메르의 실제 보유 내역을 복제하지 않는다.

## 사용자 화면

- Telegram: 기준일, 새 글 요약, 투자 인사이트, 전체 보유 종목, 실제/목표비중, 변경사항, 현금
- HTML: 표 중심의 현재 보유 종목, 오늘의 변경, 관심종목, 과거 편출 종목, 상세 근거

## 포트폴리오 원칙

- 메르 직접 언급과 메르 논지 기반 AI 추론을 명확히 구분한다.
- 단순 언급은 관심종목으로만 남긴다.
- 개별주 목표비중은 10%, 섹터·산업 ETF 목표비중은 30%를 넘지 않는다.
- 승인된 목표비중의 합계 외 잔여분은 현금이다.
- KOSPI200과 S&P500은 비교용 벤치마크이며 모델 보유 자산으로 자동 편입하지 않는다.

## 선택적 판단 개선

운영은 PC·자체 서버 없이 GitHub 제공 실행 서버의 예약 실행으로 수행해야 한다.
현재 Gemini API 자동화가 이 구조다. 고정 인증 호스트가 필요한 추가 구독 로그인
구현은 운영 대안에서 제외한다. GPT를 추가한다면 API 키 또는 Copilot Actions
사용 권한 기반의 무인 실행 경로를 별도 구현·검증해야 한다.

기존 Gemini 요약·판단 자동화가 기본이다. ChatGPT 공식 구독 로그인 판단은 별도로
선택할 수 있고, 모델 사이에 자동 전환하지 않는다. 페르소나를 수동으로 사용하는 방식과
Python 코드가 로그인된 계정의 모델을 호출하는 방식은 서로 다른 연결이다.

개선 문맥은 현재 보유 판단의 원문 연결과 아직 해결되지 않은 위험을 보존하고 반복
이력을 줄인다. 원문 근거 검사를 모델의 기존 교정 단계에 연결한다. 긍정·부정 표현이
섞인 근거만으로 새로 편입하거나 비중을 늘리면 교정을 요청한다. 기존 보유 유지·축소를
이 추가 검사 때문에 강제로 매도하지 않는다.

동일 입력 비교는 Telegram 전송과 운영 상태·성과 원장 갱신 없이 실행한다. 운영에
반영하기 전 근거 적합성·교정 횟수·사용량을 실모델로 확인해야 한다. 수익률 평가는
당시 가용 입력과 가격·비용을 고정한 별도 실험이며, 문맥 감소나 로그인 연결만으로
수익률이 높아졌다고 판단하지 않는다.

Gemini 실모델 비교는 기존 저장소 키로 별도 실행할 수 있다. ChatGPT 최초 인증 완료를
기다리지 않고 기존 입력과 개선 입력의 근거 적합성·사용량을 먼저 확인한다.

2026-10-06 실제 실험에서 기존·최초 개선 판단은 근거 검사에 실패했다. 교정 안내를
보완한 v3은 1회 교정 후 기존 6종목·비중을 유지하고 미검증 신규 국채 ETF 편입을
보류해 기존 검사를 통과했다. 과거 미검증 근거를 새 검증으로 바꾸지 않았고
수익률 개선을 입증하지 않았다. [실모델 결과](validation/gemini-live-20261006.md).
