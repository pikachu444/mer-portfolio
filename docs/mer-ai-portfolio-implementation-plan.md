# 메르AI 포트폴리오 구현 기준

이 프로젝트는 메르 블로그 글을 수집해 LLM으로 요약·분석하고, 사용자가 살펴볼 종목 또는 섹터 ETF와 그 근거를 Telegram 및 HTML에 제공한다.

## 판단과 비중

- LLM은 원문 요약, 투자 인사이트, 메르 직접 언급과 AI 추론의 구분, 종목별 근거·위험·무효화 조건을 작성한다.
- `proposed_weight`는 기존 판단 흐름에서 만들어진 제안값을 사용한다.
- 런타임은 개별주 10%, 섹터·산업 ETF 30% 상한만 적용한다.
- 목표비중 합계가 100%를 넘을 때만 비례 축소한다. 남는 비중은 현금이다.
- 점수, 슬리브, 변동성 기반 배분, 최소 현금 규칙, 시장 베타 자동 편입은 사용하지 않는다.

## 출력

- Telegram은 글 요약, 인사이트, 전 보유 종목의 실제/목표비중, 오늘의 변경, 현금, 상세 HTML 링크를 짧게 제공한다.
- HTML은 표 중심으로 보유 종목과 오늘의 변경을 분리하고, 상세 행에 원문·근거·위험을 제공한다.
- 사용자 화면에는 validator, schema, provenance 등 내부 용어를 노출하지 않는다.

## 선택적 ChatGPT 경로와 개선 실험 (2026-10-06)

### 최신 운영 요구사항

- GitHub 제공 실행 서버의 예약 실행으로 완전 자동 운영한다. 개인 PC·고정 자체 서버를 운영 전제로 추가하지 않는다.
- 기존 Gemini API 자동화는 유지한다. 아래 구독 로그인 구현은 운영 대안에서 제외하고 선택적·과거 구현으로 보존한다.
- GPT 자동 판단의 별도 대안은 OpenAI API 키 또는 GitHub Copilot CLI의 Actions 토큰 인증이다. OpenAI API는 사용량 요금이 있고 Copilot은 계정의 사용 권한·AI 크레딧 조건이 필요하다. 두 대안은 현재 미구현·미검증이며 비용이 발생하는 실호출이나 구독 변경은 실행하지 않았다.
- 원문 대상과 근거 연결, 시점별 투자 성과 검증은 로그인 여부와 독립적으로 계속 평가한다.

공식 근거: [OpenAI API 키](https://developers.openai.com/api/docs/quickstart),
[API 요금](https://developers.openai.com/api/docs/pricing),
[Copilot Actions 인증과 과금](https://docs.github.com/en/copilot/concepts/agents/copilot-cli/copilot-cli-in-github-actions).

### 합의됨

- 사용자 요청에 따라 Gemini 글별 요약과 기본 투자 판단 경로를 유지한다. ChatGPT 구독 로그인은 선택 가능한 판단 제공자로 추가한다.
- 기존 자동 운영과 실제/목표비중 정책은 변경하지 않는다. 모델 간 자동 fallback을 추가하지 않는다.
- 로그인은 OpenAI 공식 Sign in with ChatGPT OAuth 경로를 사용하며 자격 증명은 저장소·출력·로그에 기록하지 않는다. 지속 인증은 로컬 또는 고정된 자체 실행 서버에 저장한다.
- 비교는 같은 글 요약·검증 신호·기준 상태를 사용하며 Telegram 전송과 운영 상태·수익률 원장 갱신을 하지 않는다.
- 문맥 개선은 현재 보유 판단, 연결 신호, 원문 인용, 위험·무효화 조건을 보존하고 반복 이력·중복 문맥을 줄이는 실험 옵션으로 둔다.
- 개선 평가에는 근거 링크의 방향 적합성, 직접 판단과 AI 추론 구분, 종목 코드 검증, 비중 일관성, 검증 통과율, 사용량과 지연을 포함한다. 수익률 개선은 시점별 입력·가격·비용을 고정한 별도 검증 없이 주장하지 않는다.
- 요청 예산은 재시도·형식 교정도 포함해 실제 생성 시도 직전에 차감한다. 이미 저장된 요약을 다시 생성하지 않는다.
- 원문·방향 적합성 및 재조정 보유 검토 오류를 `focused`의 기존 1회 교정 단계에 전달한다. 검증을 완화해 잘못된 결과를 통과시키지 않는다.
- 긍정·부정 표현이 섞인 원문 방향은 자동으로 다시 분류하지 않는다. 해당 근거만으로 신규 편입·비중 증가를 제안하면 교정을 요청하고, 별도의 검증된 적합 근거가 있으면 기존 기준으로 판단한다. 유지·축소에는 추가 차단을 적용하지 않는다.
- 로컬 실험 요청 예산 소진을 Gemini 서버 quota 오류와 구분하여 불필요한 재시도와 대기를 차단한다.

### 완료 조건

- Gemini 기존 테스트와 새 로그인·스트림·제공자 선택·비교 격리 테스트가 통과한다.
- 비교 실행 결과에 입력 해시, 제공자·모델·문맥 버전, 검증 결과와 실제 요청 수가 남는다.
- 사용자 계정 로그인과 실제 모델 비교 여부를 오프라인 검증과 구분해 기록한다.

### 구현·검증 기록

구현과 오프라인 회귀 검증 결과는 [2026-10-06 검증 기록](validation/chatgpt-provider-20261006.md)에 남긴다.
실제 OAuth 승인이 저장되지 않은 현재 환경에서는 생성 요청 전에 실행을 보류했다.
실계정 연결, 실모델 판단 품질과 투자 수익률은 완료 항목으로 표시하지 않는다.

이 문단은 최초 오프라인 구현 시점의 상태다. 아래 추가 실험에서 Gemini를 실제로
호출했으며 계정 연결·원문 대상·수익률의 남은 한계는 별도로 기록한다.

### 실제 Gemini 비교 추가 합의 (2026-10-06)

사용자가 실제 검증과 연결을 요청했으므로 기존 저장소의 Gemini 키로 두 판단 경로를
독립 실행한다. 저장된 재조정 입력을 사용하고 전체 생성 요청 상한은 교정·재시도 포함
4회다. 새 요약·Telegram·상태·원장 갱신은 실행하지 않는다. 별도 기능 브랜치의 전용
워크플로 변경 한 번으로 실행하고 결과를 아티팩트로 받아 분석한다. 기존 매일 자동화는
변경하지 않는다. API 연결 성공, 근거 검증 통과, 수익률 검증을 별도로 보고한다.

첫 실행은 생성 요청 전에 SDK 연결이 닫혀 두 경로가 보류됐다(생성 0회). 비교 래퍼가
SDK 소유 객체를 유지하도록 수정했다. 실제 SDK 객체의 수명 회귀 테스트를 추가해
모의 전송 테스트가 놓친 문제를 재현·차단하고 수정 후 실모델 비교를 다시 실행한다.

수정 후 실제 Gemini 응답 4회는 정상 수신했지만 기존·개선 두 경로 모두 연결 근거
검증에 실패했다. v1의 개선 효과는 입증되지 않았다. `focused-source-v2`는 교정 오류에
종목과 신호 ID, 원문 대상·방향·URL 문제를 구체적으로 전달한다. 반대 근거는 위험·
무효화 검토에서 설명하고 보유·매수의 지지 연결에 섞지 않도록 안내하며, 유효한 기존
원문 연결은 유지한다. 교정이 실제 무효화 검토나 필요한 축소·매도를 건너뛰도록
강요하지 않는다. 개선 경로만 추가 최대 2회로 재검증한다(이번 실험 총 상한 6회).

v2도 두 정상 응답 뒤 신규 미국 10년물 국채의 근거가 검증되지 않아 보류됐다. v3에서는
처음 발견한 보유 연결 오류 외에 모든 신규 편입의 미검증 근거도 교정 진단에 포함한다.
검증되지 않은 편입을 관심종목·추가 검토로 남기도록 안내한다. 마지막 재검증은 최대
2회이며 실험 전체 생성 상한은 8회다. 이 역시 실제 결과를 확인하기 전 효과를 주장하지 않는다.

v3의 두 실제 응답 중 첫 판단은 보유 연결 오류로 교정됐고 두 번째 판단은 공통 검사를
통과했다. 기존 6종목과 목표비중은 모두 유지됐으며 미검증 IEF 신규 편입은 실행하지
않았다. 총 8회 생성 응답을 받았고 한도 오류는 없었다. 단일 입력·각 변형 1회 실험이므로
통과율 향상이나 수익률 개선은 입증하지 못했다. 기존 보유 6개와 IEF 관심종목의
`legacy_unvalidated` 상태는 남아 있다. 이를 새로 검증된 메르의 판단처럼 표시하지 않는다.
상세 결과와 사용량은 [실모델 기록](validation/gemini-live-20261006.md)에 남긴다.

기존 미검증 종목의 원문 대상·직접 판단/AI 추론을 다시 검토하고 시점별 입력·가격·비용을
고정한 전략 비교를 준비하는 항목을 작업 목록에 추가했다. 새로운 비중·현금 정책을
이 실험 결과만으로 채택하지 않는다.
